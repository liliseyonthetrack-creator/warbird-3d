# Sky Warbird 3D — v2.0

Full Combat Upgrade: Black Falcon, flight physics, wing movement, missiles, boss, and improved battlefield.

What's new in v2.0
- Black Falcon player model with wing animation
- Flight physics with velocity, acceleration, drag and boost
- Homing missiles (limited count) and gunfire
- Enemy waves and a boss (Sky Dreadnought) with special attacks
- Improved battlefield (larger ground, more towers, clouds)
- HUD updated for weapons and mission alerts

Controls (new)
- Fire gun: Space
- Launch missile: X (2 missiles per mission)
- Boost: Shift
- Toggle camera: C
- Toggle sound: M

Notes
- This is a prototype: models are low-poly procedural meshes to keep load small for GitHub Pages.
- Next steps: replace the procedural boss with a refined model, add mission objectives UI, add audio samples and particle textures.
